EL PRINCIPIO RECTOR

El responsable de Experiencia Solar es el dueño del caso, no el canal por donde pasa todo.

Todo lo demás de este manual —los plazos, las plantillas, las señales, las pantallas— existe para sostener eso. Si alguna vez una regla de acá se pelea con este principio, gana el principio y la regla se corrige.
